GESTOR DE ORIENTACIÓN — EXPLICACIÓN DEL CÓDIGO PYTHON, LÍNEA POR LÍNEA
==========================================================================

Este documento explica los dos archivos de Python del proyecto:

  gestor.py  El "motor": conexión a MongoDB, importar/exportar, filtros, PDF y macros de consola.
  app.py     La interfaz web (Flask): inicio de sesión, rutas que usa la página y descargas.
             Reutiliza las funciones de gestor.py.

(La página index.html y login.html están escritas en HTML/CSS/JavaScript, no en Python;
aquí solo se explica el Python.)

CÓMO LEER ESTE DOCUMENTO
Cada bloque muestra el código original con su número de línea ("  40 | ...") y debajo,
después de "»", lo que hace. Las líneas muy parecidas o que forman una sola instrucción
(listas largas, paréntesis que continúan) se explican juntas.

CONCEPTOS BÁSICOS
  Módulo / import ... Archivo de Python que se "trae" para usar sus funciones.
  Función (def) ...... Bloque de instrucciones con nombre; se ejecuta cuando se la llama.
  Variable ........... Un nombre que guarda un valor (ESCUELA = "...").
  Lista [ ] .......... Valores en orden: ["a", "b"].
  Diccionario { } .... Pares clave: valor: {"nombre": "Ana"}. Un registro de MongoDB es un diccionario.
  f-string ........... Texto con f"...{variable}..." donde lo que está entre llaves se sustituye.
  Decorador (@) ...... Etiqueta sobre una función que le agrega un comportamiento (@macro, @app.get).
  try / except ....... "Intenta esto; si falla, haz lo otro" (evita que el programa se cierre).
  MongoDB ............ Base de datos de documentos. "Colección" ~ hoja (alumnos, canalizaciones).
  Índice ............. Atajo para encontrar datos rápido sin leer toda la colección.
  Upsert ............. Actualizar si existe, crear si no. Por eso reimportar no duplica.
  Bulk ............... Enviar muchas operaciones juntas: mucho más rápido que una por una.
  JSON ............... Formato de texto para intercambiar datos: {"alumnos": [...]}.
  Hash ............... Huella irreversible de una contraseña: nunca se guarda la contraseña real.
  Sesión / cookie .... Marca en el navegador que recuerda que ya iniciaste sesión.
  Ruta (@app.get) .... Dirección web a la que la página pide o envía datos (/api/alumno/123).

  MONGO_DB .... nombre de la base.
  HOST / PORT . quién puede abrir la página (127.0.0.1 = solo esta PC; 0.0.0.0 = toda la red).
